# Slide 1: Welcome to Deep Learning

## What to Say (30-60 seconds)

Welcome, everyone! Today we're embarking on an exciting journey into deep learning - one of the most transformative technologies of our time. Deep learning is a subset of machine learning that uses artificial neural networks with multiple layers to learn from data. Think of it as teaching computers to learn the way humans do - through experience and examples.

In this course, we'll start from the fundamentals and build up to modern architectures like transformers. We'll cover how neural networks actually work, how they learn through backpropagation, and how to apply them to real-world problems. By the end, you'll understand not just how to use deep learning frameworks, but the mathematics and intuition behind them.

Our learning objectives are straightforward: understand neural network architectures, master training algorithms, and gain hands-on experience with different types of networks for various tasks.

**Check Understanding:** Before we dive in, can anyone tell me what makes "deep" learning different from traditional machine learning?

## Key Points
- Deep learning uses multi-layered neural networks
- Course covers fundamentals to advanced architectures
- Focus on both theory and practical applications
- Builds mathematical intuition alongside coding skills

## Common Student Questions

**Q: Do I need advanced math?**
A: You'll need basic calculus (derivatives) and linear algebra (matrices). We'll review the key concepts as needed.

**Q: What programming experience is required?**
A: Basic Python knowledge is helpful. We'll use frameworks like PyTorch/TensorFlow that abstract much of the complexity.

**Q: How is this different from AI or machine learning?**
A: AI is the broad field, machine learning is a subset using algorithms to learn from data, and deep learning is a subset of ML using neural networks with many layers.
